# 🎬 claude-skills

Кастомные скиллы для Claude Code.

## 📦 Скиллы

### `/dub-guide` — Пошаговый гайд переозвучивания видео

Интерактивный гайд из **11 этапов** для переозвучивания видео на другой язык через скилл `/dub`.

**Возможности:**
- ✅ Поддержка 40+ языков (русский, французский, китайский, английский и др.)
- ✅ Озвучка через бесплатный TTS (edge-tts)
- ✅ Автоматическое отделение музыки от голоса (demucs)
- ✅ Синхронизированные субтитры
- ✅ Фонетическая озвучка для брендов (машина произносит "Бикс", субтитры показывают "Bix")

**Пайплайн:**
1. Получить видео
2. Транскрипт оригинала
3. Перевод на целевой язык
4. Работа с брендами
5. Выбор голоса
6-10. Автоматическая озвучка и сведение
11. Проверка результата

**Первый запуск:**
```bash
/dub-guide
```

**Справочники:**
- `dub-guide/reference/voices.md` — таблица голосов и коды языков
- `dub-guide/reference/requirements.md` — требования и зависимости

**Документация:**
- `dub-guide/SKILL.md` — полное описание всех 11 шагов


   ```
   video_ru_2026-08-15.mp4
   ```

## 📋 Требования

- Python 3.8+
- edge-tts (синтез речи)
- demucs (отделение музыки)
- ffmpeg (видео)
- 4+ ГБ ОЗУ (рекомендуется 8+ ГБ для видео > 10 минут)

Подробности: `dub-guide/reference/requirements.md`

---

## ⚠️ Известные ограничения

- **Без липсинка:** субтитры синхронизированы, но губы в видео не меняются
- **Только звук и субтитры:** видеоряд не редактируется
- **Серверные ограничения:** на Linux без видеокарты видео > 30 минут может не обработаться из-за нехватки памяти

Решение: раздели видео на части по 5 минут и обработай отдельно.

## 🐛 Частые проблемы

| Проблема | Решение |
|----------|---------|
| TTS неправильно читает бренд | Добавь фонетику на шаге 4 (например, "Bix" → "Бикс") |
| Озвучка не уложилась в видео | Сократи перевод на шаге 3 или подними ATEMPO на шаге 7 |
| Голос тихий под музикой | Подстрой громкость в параметре `volume=` на шаге 9 |
| На сервере процесс упал | Видео слишком длинное, раздели на куски (шаг 8) |

Подробнее: `dub-guide/SKILL.md` → раздел "Частые грабли"
