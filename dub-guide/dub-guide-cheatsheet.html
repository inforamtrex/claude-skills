📍 Шаг 0: Подготовить куки (один раз)

Куки нужны, чтобы скачать видео с YouTube (защита от ботов). После установки расширения куки обновляются за 10 секунд.

  1. Установить расширение Chrome — поиск в Chrome Web Store: Get cookies.txt (автор Erick Veil)
  2. Зайти на YouTube, нажать на иконку расширения, нажать Export
  3. Сохранить в файл cookies.txt в папку G:\Downloads\
  4. ✓ Готово! Куки обновлены и готовы к использованию
💡 Подробнее про куки: см. раздел «🍪 YouTube и куки» ниже — там пошагово с картинками

1️⃣ Скачать видео (скилл /download)

Используй встроенный скилл для скачивания. Он поддерживает YouTube, TikTok, Instagram и 1000+ других сайтов.

/download "https://www.youtube.com/watch?v=dQw4w9WgXcQ"

Видео скачается в папку G:\Downloads\ с именем вроде Название видео [ID].mp4

2️⃣ Переозвучить видео (скилл /dub-guide, 11 шагов)

Запусти интерактивный гайд. Он проведёт тебя через все этапы: транскрипт → перевод → озвучка → субтитры.

/dub-guide

Гайд спросит путь к видео, язык оригинала, язык перевода, и язык озвучки. Потом автоматически обработает видео.

3️⃣ Результат

Ты получишь два файла в папке с видео:

  • video_ЯЗЫК_ДАТА.mp4 — видео с новой озвучкой
  • video_ЯЗЫК_ДАТА.srt — субтитры (синхронизированы с видео)
✓ Всё готово! Видео переозвучено, субтитры синхронизированы.

📦Зависимости и установка

Минимальная установка

pip install edge-tts demucs torch torchaudio

Чек окружения

python -m edge_tts --help
python -m demucs --help
ffmpeg -version
ffprobe -version

Что нужно

Пакет Размер Назначение
edge-tts ~10 МБ Синтез речи (40+ голосов)
demucs ~1 ГБ Отделение голоса от музыки
torch ~500 МБ (CPU) или +500 МБ (GPU) Нейросетевой фреймворк
ffmpeg ~50 МБ Обработка видео/аудио

Требования к ОЗУ

  • 4 ГБ: для коротких видео (до 5 минут)
  • 8+ ГБ: для видео от 5 до 30 минут
  • Видео > 30 минут: раздели на куски

🍪YouTube и куки

ШАГ 1 перед дубляжом: скачиваем видео с YouTube через скилл /download. Для этого нужны куки. Инструкция ниже.

Если скачиваешь видео с YouTube, нужны куки. Они позволяют скачивать видео, защищённые геолокацией или возрастом. После установки расширения куки можно обновлять за 10 секунд.

Шаг 1: Установить расширение в Chrome

  1. Открыть Chrome Web Store: https://chrome.google.com/webstore
  2. Искать: "Get cookies.txt"
  3. Найти расширение от Erick Veil (иконка жёлтая с печеньем)
  4. Нажать "Добавить в Chrome"
  5. Подтвердить разрешения

Шаг 2: Вытащить куки с YouTube

Важно: делай это в браузере, где ты залогинен на YouTube!
  1. Откройте YouTube — зайдите на любую страницу YouTube (например, youtube.com)
  2. Нажмите на иконку расширения — в правом верхнем углу браузера (рядом с адресной строкой)
  3. Найдите "Get cookies.txt for …" — это наше расширение
  4. Нажмите кнопку "Export" (зелёная кнопка) — куки скопируются в буфер обмена

Шаг 3: Сохранить куки в файл

  1. Откройте любой текстовый редактор (Notepad, VS Code, etc.)
  2. Вставьте куки — Ctrl+V
  3. Сохраните файл с именем: cookies.txt
  4. Сохраните в рабочую папку, например: C:\Users\user\Downloads\cookies.txt
✓ Правильно:
cookies.txt (не .doc, не .rtf, ТОЛЬКО .txt)
Содержимое: таблица с колонками (domain, path, secure, expiry, name, value)

Шаг 4: Скачать видео с YouTube через yt-dlp

yt-dlp --cookies cookies.txt "https://www.youtube.com/watch?v=dQw4w9WgXcQ" -o "video.mp4"

Флаг --cookies cookies.txt указывает, какой файл с куками использовать. Если yt-dlp и cookies.txt в разных папках, указывай полный путь: --cookies "C:\Users\user\Downloads\cookies.txt"

Когда обновлять куки?

  • Куки живут несколько месяцев (зависит от YouTube)
  • Если yt-dlp выдаст ошибку 403 (доступ запрещён) — обнови куки
  • Если выходишь из YouTube-аккаунта — куки больше не работают

Частые грабли

Проблема Решение
«Файл не найден» при yt-dlp Проверь путь к cookies.txt — используй полный путь или скачивай в ту же папку, что yt-dlp
Расширение не появилось в Chrome Перезагрузи браузер (Ctrl+Shift+Delete или перезапуск)
Экспорт пустой (ничего не скопировалось) Убедись, что ты на YouTube.com, а не на другом сайте
yt-dlp выдаёт 403 даже с куками Обнови куки (сделай экспорт заново) — YouTube может их инвалидировать

⚡Командная справка

Запуск скилла

/dub-guide

python check_env.py

python -m edge_tts --list-voices | grep -i "ru-"

Тестировать голос

edge-tts --voice "ru-RU-DmitryNeural" --text "Привет мир" --write-media output.mp3

python -m demucs video.mp4 -n mdx_extra

Синхронизировать субтитры (ffmpeg)

ffmpeg -i video.mp4 -i audio_ru.mp3 -c:v copy -c:a aac -map 0:v:0 -map 1:a:0 output.mp4

🐛Частые проблемы

Проблема Решение
TTS неправильно произносит бренд Добавь фонетику на шаге 4 (Bix → Бикс)
Озвучка не уложилась в видео Сократи перевод (шаг 3) или подними ATEMPO (шаг 7)
Голос тихий под музикой Подстрой volume= в параметрах шага 9
На сервере процесс упал Видео слишком длинное — раздели на куски по 5 минут
ffmpeg not found Переустанови: `winget install ffmpeg` (Windows)
ModuleNotFoundError: edge_tts `pip install edge-tts` (или не установлен вообще)
Субтитры не видны Проверь кодировку (UTF-8) и шрифт (Arial для кириллицы)

⚠️Известные ограничения

  • Без липсинка: субтитры синхронизированы, но губы не меняются
  • Только звук и субтитры: видеоряд не редактируется
  • Серверные ограничения: Linux без видеокарты может упасть на видео > 30 минут
  • CJK-шрифты на сервере: китайские субтитры собирай на Windows/macOS
  • Первый запуск slow: скачивается модель demucs (~1 ГБ)

Решение для больших видео

Раздели видео на части по 5 минут, обработай отдельно, потом склей:

# Разрезать
ffmpeg -i video.mp4 -c copy -segment_time 300 part_%03d.mp4

# Обработать каждый part_*.mp4
/dub-guide

# Склеить
ffmpeg -f concat -safe 0 -i list.txt -c copy output.mp4
