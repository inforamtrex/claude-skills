## Другие языки

Полный список голосов edge-tts:
```bash
python -m edge_tts --list-voices
```

Поиск по языку:
```bash
python -m edge_tts --list-voices | grep -i "<язык>"
# Примеры:
# python -m edge_tts --list-voices | grep -i spanish
# python -m edge_tts --list-voices | grep -i german
# python -m edge_tts --list-voices | grep -i japanese
```

## Качество голосов

- **Лучшее качество:** RU (Dmitry/Svetlana), EN (Guy/Jenny)
- **Хорошее:** FR (Henri/Denise)
- **Иногда странный темп:** ZH (требует дополнительной настройки ATEMPO)

## Выбор мужского vs женского

- Если **видео развлекательное/промо** → женский голос звучит естественнее
- Если **видео серьёзное/обучающее** → подходит оба
- Если **оригинал озвучивал мужчина** → можно повторить, но не обязательно
- **Главное:** голос должен быть ясным и разборчивым при выбранном ATEMPO

## Тестирование голоса

Перед полным дубляжом проверь голос на коротком отрывке:
```bash
echo "Добро пожаловать! Это тестовое сообщение." > test.txt
python -m edge_tts --voice ru-RU-SvetlanaNeural --file test.txt --write-media test.mp3
# Слушай test.mp3 и решай, подходит ли голос
```

## Специальные случаи

### Акценты и диалекты
edge-tts **не поддерживает акценты** напрямую. Если нужен акцент:
- Можешь использовать ElevenLabs (платно, лучше качество)
- Или оставить стандартный голос

### Скорость речи
Сам edge-tts не позволяет менять скорость, но можно:
- Использовать ATEMPO на шаге 7 (замедлит или ускорит весь звук)
- Или обработать через ffmpeg после озвучки: `atempo=1.2` (20% ускорение)
