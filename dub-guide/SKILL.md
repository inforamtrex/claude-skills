# dub-guide — пошаговый интерактивный гайд переозвучивания видео

Проводит через **11 этапов** переозвучивания видео с одного языка на другой.

## 🎯 Зачем этот гайд

Скилл `/dub` полностью автоматизирует озвучку видео, но первый раз можно запутаться:
- Где взять видео и как его измерить?
- Как правильно перевести, чтобы озвучка уложилась в длину?
- Какой голос выбрать?
- Что делать с брендами (чтобы машина их правильно произнесла)?

Этот гайд проходит все шаги **в правильном порядке** с объяснениями.

---

## 📋 Пайплайн (11 шагов)

### **Шаги 1–5: Подготовка (работа Claude)**
На этих шагах нужна твоя голова, а не автоматика.

#### Шаг 1: Получить видео
- **Задача:** скачать видео или получить файл
- **Как:**
  - Если ссылка (YouTube, Вимео) → вызови скилл `/download <ссылка>`
  - Если локальный файл → используй его
- **Что дальше:** замерь длину видео
  ```bash
  ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 VIDEO.mp4
  ```
  Запомни это число (например, **5:30** = 330 секунд). Это критично для шага 7.

---

#### Шаг 2: Получить транскрипт оригинальной озвучки
- **Задача:** вытащить текст того, что говорит диктор в видео
- **Как:**
  - Если рядом с видео лежит `.txt` → бери его
  - Иначе распознай речь:
    ```bash
    python -m faster_whisper VIDEO.mp4 --model small --output_format txt
    ```
  - Проверь результат — машина может ошибиться в именах и терминах
- **Что дальше:** сохрани текст в файл `original_transcript.txt`

---

#### Шаг 3: Перевести на целевой язык
- **Задача:** качественный живой перевод (не машинный подстрочник)
- **Правила:**
  - Переводи образно и живо, как книга, не как ChatGPT
  - Соблюдай стиль оригинала
  - Для русского: среднее тире (–), не рубленые фразы
  - **Компактность:** озвучка часто получается длиннее оригинала. Формулируй короче, длинные фразы ужимай, но смысл не теряй
- **Что дальше:** сохрани в `translated_text.txt`

---

#### Шаг 4: Найти бренды и собрать ДВЕ версии текста
- **Задача:** машина (TTS) будет коверкать английские бренды, нужно её обмануть
- **Как:**
  1. Прочитай перевод и найди все английские названия/бренды (Bix, USDC, Visa, OpenAI и т.п.)
  2. Предложи пользователю фонетическое написание для каждого:
     - **Bix** → как произнести? «Бикс» (RU), «Бике» (FR), «比克斯» (ZH)
     - **USDC** → «юэс-ди-си» или просто буквы?
  3. Собери **две версии текста:**
     - `ru_script.txt` — текст для озвучки (Бикс, юэс-ди-си) — TTS читает это
     - `repl.txt` — файл замен для субтитров:
       ```
       Бикс=>Bix
       юэс-ди-си=>USDC
       ```
       Каждая замена с новой строки.
- **Что дальше:** обе версии готовы. Файлы `ru_script.txt` и `repl.txt` нужны на шаге 10.

---

#### Шаг 5: Спросить голос
- **Задача:** выбрать голос TTS (мужской или женский)
- **Таблица голосов:**
  | Язык | Мужской | Женский |
  |------|---------|---------|
  | RU | ru-RU-DmitryNeural | ru-RU-SvetlanaNeural |
  | FR | fr-FR-HenriNeural | fr-FR-DeniseNeural |
  | ZH | zh-CN-YunxiNeural | zh-CN-XiaoxiaoNeural |
  | EN | en-US-GuyNeural | en-US-JennyNeural |
  
  Для другого языка:
  ```bash
  python -m edge_tts --list-voices | grep -i "<code>"
  ```
- **Что дальше:** скажи пользователю, какой голос выбран, и переходи к шагу 6.

---

### **Шаги 6–10: Автоматика (работа скилла `/dub`)**
На этих шагах машина делает всю работу.

#### Шаг 6: Озвучка + тайминги
```bash
python -m edge_tts --voice <ГОЛОС> --file ru_script.txt \
   --write-media voice.mp3 --write-subtitles words.vtt
```
**Результат:** `voice.mp3` (аудиофайл) + `words.vtt` (тайминги каждого слова)

---

#### Шаг 7: Подгонка длины под видео
- **Задача:** озвучка должна уложиться в длину видео
- **Как:**
  1. Замерь длину файла `voice.mp3`:
     ```bash
     ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 voice.mp3
     ```
  2. Считай **ATEMPO** (скорость воспроизведения):
     ```
     ATEMPO = длина_озвучки / (длина_видео - 1)
     ```
     Пример: озвучка 4 минуты, видео 5 минут 30 секунд
     ```
     ATEMPO = 240 / (330 - 1) = 240 / 329 = 0.729
     ```
  3. **Если ATEMPO > ~1.15:** голос будет затараторивать, нужно СОКРАТИТЬ перевод (вернись на шаг 3) или добавить естественные паузы
  4. **Если ATEMPO < ~0.85:** озвучка слишком медленная, можно ускорить, но в пределах 1.15

---

#### Шаг 8: Отделить музыку от голоса оригинала
```bash
python -m demucs --two-stems=vocals -o demux VIDEO.mp4
```
**Результат:** папка `demux/htdemucs/<имя>/`, в ней файл `no_vocals.wav` (чистая музыка, голос убран)

**⚠️ Серверные ограничения:**
- На сервере Jarvis это медленно: видео > 5 минут считает часами
- Если видео очень длинное — лучше считать на ПК (есть видеокарта)

---

#### Шаг 9: Свести озвучку + музику в видео
```bash
ffmpeg -y -i VIDEO.mp4 -i no_vocals.wav -i voice.mp3 \
  -filter_complex "[2:a]atempo=ATEMPO,adelay=300|300,volume=1.7[v];[1:a]volume=0.30[m];[v][m]amix=inputs=2:duration=first:normalize=0,alimiter=limit=0.95[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k -shortest voiced.mp4
```
**Параметры:**
- `atempo=ATEMPO` — скорость озвучки
- `volume=1.7` (голос) / `volume=0.30` (музика) — громкость. Подстрой если музика глушит голос

**Результат:** `voiced.mp4` (видео + новая озвучка + музика)

---

#### Шаг 10: Пересчёт тайминга субтитров и вшивание
```bash
python rescale_srt.py words.vtt subs.srt ATEMPO 0.3 <ДЛИНА_ВИДЕО> repl.txt
```
**Что это делает:**
- Пересчитывает тайминги под новый темп (ATEMPO)
- Возвращает оригинальные названия брендов (Бикс → Bix)
- Выдаёт финальный файл `subs.srt`

**Вшить субтитры в видео:**
```bash
ffmpeg -y -i voiced.mp4 \
  -vf "subtitles=subs.srt:force_style='FontName=Arial,FontSize=22,Bold=1,PrimaryColour=&H00FFFFFF,OutlineColour=&HC0000000,BorderStyle=1,Outline=2,Shadow=1,MarginV=45,Alignment=2'" \
  -c:v libx264 -preset medium -crf 20 -c:a copy "ИМЯ_lang_дата.mp4"
```
**Результат:** финальное видео с вшитыми субтитрами `ИМЯ_ru_2026-08-15.mp4`

---

### **Шаг 11: Проверка (работа Claude)**
- **Задача:** убедиться, что всё синхронизировано и читаемо
- **Как:**
  1. Вытащи 1-2 кадра с субтитрами:
     ```bash
     ffmpeg -ss 00:01:30 -i FINAL.mp4 -frames:v 1 check.png
     ```
  2. Посмотри через Read — проверь:
     - Бренд на экране в оригинальном написании? (Bix, не Бикс)
     - Субтитр читаемый и не обрезан?
     - Синхронизирован ли субтитр с тем, что говорит голос?
  3. Если всё ок → готово! Если проблема → вернись на нужный шаг

## ⚠️ Частые грабли

| Проблема | Причина | Решение |
|----------|---------|---------|
| TTS читает бренд неправильно | Не добавлен фонетический вариант | Вернись на шаг 4, добавь фонетику |
| Озвучка не уложилась в видео | ATEMPO слишком большой | Сократи перевод или добавь паузы (шаг 3) |
| Голос тихий под музикой | Неправильно настроена громкость | Подними `volume=1.7` или понизь `volume=0.30` (шаг 9) |
| На сервере процесс умер с Killed | Не хватило памяти при demucs | Раздели видео на куски 3-5 минут, обработай по отдельности (шаг 8) |
| Субтитры на кириллице/иероглифах не видны | Неправильный шрифт | Для CJK используй Microsoft YaHei вместо Arial (шаг 10) |
| На сервере CJK-субтитры вообще не работают | Сервер без CJK-шрифтов | Собирай китайское только на ПК (шаг 10) |
